OS: macOS / Windows / Linux 均可
Python: 3.8+
依赖: sherpa-onnx, sounddevice, soundfile
是否需要GPU: 否（纯CPU推理）
sherpa-onnx>=1.12.0
sounddevice>=0.4.6
soundfile>=0.12.1
numpy>=1.21.0

找到入口：打开剪映APP，任意创建一个项目。在底部工具栏找到并点击 【音频】 ，然后在顶部菜单栏向左滑动，找到 【克隆音色】 功能。

录制声音：点击进入后，系统会引导你录制一段声音样本。你只需要根据提示，用平常说话的语气和音量读出屏幕上的例句即可。朗读时长通常只需5到10秒。

生成并使用：录制完成后，点击提交，系统会花大约十几秒到一分钟的时间来生成你的专属音色。之后，为视频配音时，只需要正常输入文字，然后点击 【文本朗读】 ，在“我的”或者“克隆音色”列表里，就能找到并选择刚才创建的声音了。

我选择的为清朗男声
