  本视频主要围绕“具身智能与人形机器人”这一主题展开，重点讨论人工智能从只存在于虚拟环境，逐渐走向现实世界的发展趋势。
随着人工智能技术的发展，现在的AI在语言处理、图像识别等方面已经很强了，但它们大多还是停留在“屏幕里”，并不能真正理解和接触现实世界。具身智能的出现，就是让AI拥有“身体”，能够通过与环境的互动来学习和做出判断，这种方式更接近人类的认知过程。
在这样的背景下，人形机器人逐渐成为研究的热点。因为人类的生活环境本身就是按照人体来设计的，人形机器人更容易适应这些场景。同时，结合大模型技术，机器人也开始具备更强的理解和执行任务的能力。
我会从基本概念、技术原理、应用场景以及未来发展等方面，对具身智能进行一个整体介绍，并简单谈一谈它可能带来的影响。
