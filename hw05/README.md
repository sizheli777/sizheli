# hw05 - CNN 手写数字识别

## 目录结构
- `simple_cnn.py` - 任务一极简CNN模型定义
- `lenet5.py` - 任务二LeNet-5模型定义
- `train_simple_cnn.py` - 极简CNN训练脚本
- `train_lenet5.py` - LeNet-5训练脚本
- `run_all.py` - 一键运行两个模型训练
- `report.md` - 实验报告
- `debug_notes.md` - 调试记录
- `requirements.txt` - 依赖包
