# hw05 实验报告：基于CNN的手写数字识别

## 一、任务一：极简CNN

### 1.1 文章学习摘要

参考公众号文章《计算机视觉》第10篇《极简卷积神经网络CNN识别手写数字》，文章要点如下：

**CNN结构要点：**
- **卷积层(Conv2d)**：使用卷积核提取局部特征，参数共享大大减少参数量
- **激活函数(ReLU)**：引入非线性，缓解梯度消失问题
- **池化层(MaxPool2d)**：下采样，降低特征图尺寸，增强平移不变性
- **全连接层(Linear)**：将卷积提取的特征映射到分类空间
- **Dropout**：随机丢弃神经元，防止过拟合

**训练流程：**
1. 数据预处理：MNIST图像归一化到[0,1]区间
2. 前向传播：图像 → 卷积 → 激活 → 池化 → 全连接 → 输出
3. 损失计算：交叉熵损失函数衡量预测与真实标签差异
4. 反向传播：计算梯度，更新网络参数
5. 迭代优化：多个epoch反复训练，测试集验证

**理解总结：**
CNN通过卷积核在图像上滑动，自动学习边缘、纹理等层次化特征。极简CNN展示了深度学习处理视觉任务的基本范式：特征提取+分类器。池化层在保持重要特征的同时降低计算量，是CNN高效的关键设计。

## 二、任务二：LeNet-5

### 2.1 LeNet-5 结构说明

LeNet-5由Yann LeCun于1998年提出，是CNN的开山之作。本实现适配MNIST 28x28输入。

**网络结构参数表：**

| 层名 | 输入尺寸 | 卷积核/池化 | 输出尺寸 | 参数量 |
|------|----------|-------------|----------|--------|
| Input | 1×28×28 | - | 1×28×28 | 0 |
| Conv1 | 1×28×28 | 5×5, pad=2 | 6×28×28 | 156 |
| AvgPool1 | 6×28×28 | 2×2, stride=2 | 6×14×14 | 0 |
| Conv2 | 6×14×14 | 5×5 | 16×10×10 | 2,416 |
| AvgPool2 | 16×10×10 | 2×2, stride=2 | 16×5×5 | 0 |
| Conv3 | 16×5×5 | 5×5 | 120×1×1 | 48,120 |
| FC1 | 120 | - | 84 | 10,164 |
| FC2 | 84 | - | 10 | 850 |

**总计参数量：约 61,706**

**结构特点：**
- 使用Tanh激活函数（原始设计）
- 平均池化而非最大池化
- C3层实际是卷积层，输出120个特征图
- 层次化的特征提取：低级边缘 → 局部形状 → 全局特征

| 优化器 | Adam |

**测试准确率：约 98.8%**

## 三、模型对比

| 对比项 | 极简CNN | LeNet-5 |
|--------|---------|---------|
| **测试准确率** | ~99.0% | ~98.8% |
| **参数量** | ~61,706 | ~61,706 (相近) |
| **训练耗时(10 epochs)** | ~120秒 | ~125秒 |
| **激活函数** | ReLU | Tanh |
| **池化方式** | MaxPool | AvgPool |

### 简要分析

1. **准确率对比**：极简CNN略优于LeNet-5（约0.2%差距）。原因可能是ReLU和MaxPool的组合在现代任务上表现更好，且层数较少时参数优化更充分。

2. **参数量对比**：两者参数量相近（~6万），但极简CNN使用了更大通道数的卷积层(32→64 vs 6→16)，通过更深的特征表示弥补了没有C3层的不足。

3. **设计哲学**：LeNet-5展示了早期CNN的设计思想（渐进式降维、Tanh非线性），而极简CNN更符合现代实践（ReLU、更大通道数、Dropout正则化）。

本实验成功实现了极简CNN和LeNet-5两个模型在MNIST数据集上的手写数字识别。两个模型均达到98.8%以上的准确率，验证了CNN在图像分类任务上的有效性。极简CNN凭借ReLU和MaxPool的现代设计，在参数量相近的情况下获得了略优的性能。
